## Dasar

| Istilah | Arti singkat |
|---|---|
| **Variabel** | Tempat menyimpan data yang punya nama (`umur = 20`) |
| **Tipe data** | Jenis data: angka (int, float), teks (string), benar/salah (boolean) |
| **Operator** | Simbol untuk operasi: `+`, `-`, `==`, `and`, `or` |
| **Fungsi** | Blok kode yang bisa dipanggil berulang kali |
| **Parameter / argumen** | Nilai yang dikirim ke dalam fungsi |
| **Return** | Nilai yang dikembalikan fungsi |
| **Komentar** | Catatan di kode yang tidak dijalankan (`# ini komentar`) |
| **Sintaks** | Aturan penulisan kode suatu bahasa |

## Alur Program

| Istilah | Arti singkat |
|---|---|
| **Kondisional (if/else)** | Menjalankan kode hanya jika syarat terpenuhi |
| **Perulangan (loop)** | Mengulang kode: `for`, `while` |
| **Rekursi** | Fungsi yang memanggil dirinya sendiri |
| **Exception** | Error saat program berjalan, ditangani dengan `try/except` |

## Struktur Data

| Istilah | Arti singkat |
|---|---|
| **Array / List** | Kumpulan data berurutan |
| **Dictionary / Hash map** | Pasangan kunci-nilai |
| **Tuple** | Kumpulan data yang tidak bisa diubah |
| **Set** | Kumpulan data unik tanpa urutan |
| **Stack** | Terakhir masuk, pertama keluar (LIFO) |
| **Queue** | Pertama masuk, pertama keluar (FIFO) |
| **Linked list, tree, graph** | Struktur data lanjutan |

## Pemrograman Berorientasi Objek (OOP)

| Istilah | Arti singkat |
|---|---|
| **Class** | Cetak biru untuk membuat objek |
| **Objek / instance** | Hasil jadi dari sebuah class |
| **Atribut / method** | Data dan fungsi milik sebuah objek |
| **Inheritance (pewarisan)** | Class baru mewarisi sifat class lain |
| **Encapsulation** | Menyembunyikan detail internal objek |
| **Polymorphism** | Satu nama method, perilaku berbeda tergantung objeknya |

## Cara Kode Dijalankan

| Istilah | Arti singkat |
|---|---|
| **Compiler** | Menerjemahkan seluruh kode sekaligus sebelum dijalankan (C++) |
| **Interpreter** | Menerjemahkan dan menjalankan baris demi baris (Python) |
| **Runtime** | Saat program sedang berjalan |
| **Debugging** | Mencari dan memperbaiki bug (kesalahan) |
| **Syntax error** | Kode salah tulis sehingga tidak bisa dijalankan |
| **Logic error** | Kode jalan, tapi hasilnya salah |

## Pengembangan Software

| Istilah | Arti singkat |
|---|---|
| **Library** | Kumpulan kode siap pakai (NumPy, matplotlib) |
| **Framework** | Kerangka aplikasi yang mengatur struktur proyek (Django, React) |
| **Package / module** | Berkas kode yang bisa diimpor |
| **API** | Antarmuka agar dua program bisa saling berkomunikasi |
| **Repository (repo)** | Tempat menyimpan proyek beserta riwayatnya |
| **Git** | Alat untuk mengelola versi kode |
| **Commit** | Satu catatan perubahan kode |
| **Branch** | Cabang kode untuk mengerjakan fitur secara terpisah |
| **Merge** | Menggabungkan satu branch ke branch lain |
| **Pull request** | Usulan perubahan kode untuk digabungkan ke repo |
| **Deploy** | Memasang aplikasi agar bisa diakses pengguna |
| **Virtual environment** | Ruang terpisah untuk library satu proyek |

## Web dan Data

| Istilah | Arti singkat |
|---|---|
| **Frontend** | Sisi tampilan yang dilihat pengguna |
| **Backend** | Sisi server dan logika di balik layar |
| **Database** | Penyimpanan data terstruktur |
| **SQL** | Bahasa untuk mengakses dan mengelola database |
| **JSON** | Format teks untuk pertukaran data |
| **Endpoint** | Alamat layanan di sebuah API |

## Istilah AI/ML

| Istilah | Arti singkat |
|---|---|
| **Model** | Program hasil pelatihan dari data |
| **Training** | Proses melatih model dengan data |
| **Inference** | Memakai model yang sudah dilatih untuk memprediksi |
| **Dataset** | Kumpulan data untuk melatih dan menguji |
| **Overfitting** | Model hafal data latih tapi buruk di data baru |
| **Prompt** | Instruksi yang diberikan ke LLM |
| **Token** | Potongan teks yang diproses model |
| **RAG** | LLM yang menjawab dengan mencari dokumen terlebih dahulu |
